# AI 文本生成

AI 文本生成用于生成单次文本，可以仅根据文字要求生成，也可以参考一张图片或运行时当前画面，例如智能配文、画面点评、测一测结果或剧情文案。

## 能力边界

- 仅有文字要求时，使用纯文本生成，不要为了调用能力而额外截图。
- 输出需要参考视觉内容时，使用图片纹理或运行时当前画面生成。
- 需要保留上下文或进行多轮交互时，使用 [AI 对话](./AI对话.md)。
- 可以传入静态纹理、运行时 RenderTexture，或直接抓取当前场景的最终输出画面。
- 生成结果只负责文本内容；加载态、展示节奏、触发条件和失败兜底由玩法脚本负责。

## 生成规范

1. 只在用户操作或明确的玩法阶段触发，不要在每帧更新中发起请求。
2. Prompt 用简洁的自然语言说明主题、文风、用途、长度和输出格式，不要复制 WF 内部的完整系统设定。
3. 纯文本生成必须提供完整 Prompt；图片生成没有特殊风格要求时可以省略 Prompt，使用默认智能配文效果。
4. 按 Brief 的输出格式与字段映射更新界面：纯文案流式输出使用累计正文，避免重复拼接；结构化输出不得直接将累计原文写入 Text 或传给语音播报。默认缓存至完成，解析并校验后按字段更新各自对象；流式展示仅允许使用可靠提取出的目标字段正文。解析失败执行已规划的失败恢复，不回退展示原始返回。
5. 必须同时处理成功和失败结果，并在请求结束后恢复玩法交互状态。
6. 不要直接构造图片上传、WF、SSE、PostMessage 或 Source ID，统一使用本能力提供的适配层。

具体接口、参数、回调、取消行为和脚本示例以 `api/ImageCaption.d.ts` 中的注释为准。
